# Лента — демо-макет новостной ленты

Готовая страница открывается по адресу: https://coderion31.github.io/lenta-demo-site/

Один HTML-файл со встроенными стилями, скриптом и картинками: работает офлайн, без сервера и сети.

Все публикации, каналы и счётчики вымышлены. Проект не связан с Яндекс Дзеном и не использует его данные.

Здесь лежит только собранная страница (`index.html`). Исходники — в приватном репозитории `lenta-demo`.
